CONTRACT / AUTHORITY CHECKREPRESENTATIVE + SHADOW PROOF

The downstream contract does not ask, “Can HYDRA find something that looks like this field?” It asks, “Is this value owned or legitimately derivable under the handoff contract?”

Discoverable data is not automatically authorized data.

If a nearby file contains a plausible value but the pipeline cannot prove that source owns the required semantic field for this handoff, HYDRA blocks the handoff instead of borrowing the value.

What the reader should understand

Normalization does not erase source identity.
Identity resolution is not semantic interpretation.
Authority is checked before downstream promotion.
Blocked is a valid outcome when ownership is missing.
Lineage and history stay attached to the result.
The final claim is narrower than the most dramatic source fragment.
